## Les étapes nécessaires pour installer et exécuter le projet

Groupe 23 Nicola Baker, 300360908 Maxime Malouf, 300238380

Cloner le projet dans le terminal :

```bash
git clone https://github.com/NicolaBaker/SEG3502Lab3.git
```

Ensuite, entrer dans le dossier du projet :

```bash
cd SEG3502Lab3/shopping-list
```

Vérifier que **Node.js**, **npm** et **Angular CLI** sont installés.

#Steps
Installer les dépendances du projet :

```bash
npm install
```

Démarrer le serveur :

```bash
ng serve
```

Si `ng serve` ne fonctionne pas, vous pouvez utiliser :

```bash
npx ng serve
```

Une fois le serveur démarré, ouvrir l'adresse suivante dans votre navigateur :

http://localhost:4200/

Tu peux ajouter un item avec le bouton **Ajouter** et le supprimer avec le bouton **Supprimer**.

Pour arrêter le serveur, faites :

```text
Ctrl + C
```
